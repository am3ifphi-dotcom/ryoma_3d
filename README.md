# ✝本質✝の教室 — 両馬二郎に話しかける 3D

桐葉高校 北棟・理数科1年B組の教室を一人称で歩き回り、教室に一人で立っている **両馬二郎** に `E` で話しかけられる Web アプリです。
話しかけると吹き出しが出て、✝本質✝の話・三重県臣・ヘイカツ・コーンスープの不在などについて、身振り手振り付きで喋ります。

## 操作

| 入力 | 動作 |
| --- | --- |
| `W` `A` `S` `D` / 矢印 | 移動 |
| `Shift` | 走る |
| マウス | 視点（クリックでポインターロック） |
| `E` / `Space` / クリック | 話しかける・次のせりふへ |
| `1` 〜 `3` | 返事を選ぶ |
| `Esc` | マウス解放（会話中なら会話終了） |
| `Tab` | 設定（モデル品質 / 影 / 感度 / 音量 / 会話記録リセット） |

スマホ・タブレットでは、画面左側ドラッグで移動、右側ドラッグで視点、右下の「話す」ボタンで会話できます。

## 起動

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # dist/ に静的ファイルを出力
npm run preview
```

## 仕組み

- **モデル**: `public/models/ryoma.glb`（Tripo PBR, 約 190 万ポリ, meshopt 圧縮）。GLB にはボーンもアニメーションも入っていないため、
  `src/character/rig.js` が **読み込み時に自動でスケルトンを生成し、頂点位置から滑らかなスキンウェイトを計算** して `SkinnedMesh` にしています。
- **LOD**: `npm run model:lod` (`scripts/make-lod.mjs`) で 20% に間引いた `ryoma_lod.glb` を生成。影の投影専用プロキシ、および「軽量モード」の表示用に使います（テクスチャはフルモデルと共有）。
- **モーション** (`src/character/animator.js`, `gestures.js`): 既製のクリップは一切使わず、
  - 体重移動付きの基本姿勢（数秒おきに重心を切り替える）
  - 呼吸・ゆらぎ・視線の泳ぎ（多重正弦ノイズ）
  - キーフレーム式ジェスチャー（頷く・肩をすくめる・✝を作る・スマホを見せる・遠い目で窓を見る…20 種類以上）
  - 全ボーンを **減衰ばね** で追従させることで、オーバーシュートや余韻のある動き
  - 頭・首・胸を配分したプレイヤーへの視線追従（たまに目線を外す）
  - 角度差が大きいと足踏みしながら体ごと向き直るターン
  - せりふの表示中は小さく体を揺らす「喋り」レイヤー
  を重ねて合成しています。
- **基本姿勢**: GLB の「気を付け」A ポーズは使いません。右手はズボンのポケット（`scripts/solve-pose.mjs` の数値 IK で手首がポケット口、指先が腿の中に来る角度を求め、ポケット内では手を縮小して腿の中に隠す）、左手はスマホ、重心を片足に乗せた崩し気味の立ち方です。
  ジェスチャーで右腕が動くときだけ手がポケットから出て、終わると戻ります（眼鏡クイッ・顎に手・頭を掻く・✝ などの接触ポーズも同じソルバーで解いています）。
- **表情** (`src/character/face.js`): モデルにブレンドシェイプが無く、顔の UV もアトラス上に散っているため、
  `scripts/make-face.mjs` で **顔メッシュから目・眉・口の三角形だけを切り出した小パッチ**（`public/models/ryoma_face.bin`）を同じスケルトンにスキニングし、法線方向に 0.5mm 浮かせてシェーダーで描きます。
  - まぶた: 肌色の板が目の開口部を上から覆う（瞬き・半目・にっこり「^ ^」・下まぶたの細め）。瞬きは 2〜7 秒間隔でランダム、たまに二度瞬き
  - 眉: 元の眉を肌色で隠し、テクスチャ付きの複製を頂点シェーダーで上下・回転（怒り / 困り / 片眉上げ）
  - 口: 元テクスチャの上に口を手続き描画（笑い・への字・開口＋歯）。せりふのタイプライター表示に合わせ、かなの母音で開き方を変える口パク
  - プリセット: neutral / smug / happy / grin / surprised / annoyed / angry / sad / think / bored / excited / serious。せりふごとにジェスチャーと気分から自動選択
- **教室** (`src/world/`): 机・椅子（インスタンシング）・黒板（ヘイカツの河岸段丘と両馬の落書き入り）・窓と室外機・廊下側の引き戸・ロッカー・掲示物などをすべてプリミティブと Canvas 生成テクスチャで構築。
- **会話** (`src/dialogue/`): 原作の口調に沿った分岐付きスクリプト。初回は自己紹介、以降は未読の話題からランダム、全部聞くと小ネタ。進行は `localStorage` に保存。
- **音** (`src/audio/sfx.js`): チャイム・足音・せりふのブリップ音・室外機の唸りを WebAudio で合成（音声ファイルなし）。

## ディレクトリ

```
index.html            エントリ (UI オーバーレイ)
src/main.js           レンダラ・ライティング・ゲームループ
src/player.js         一人称コントローラ (衝突・ヘッドボブ・タッチ操作)
src/character/        自動リグ・アニメーター・ジェスチャー・表情・キャラ読み込み
src/world/            教室の構築と手続きテクスチャ
src/dialogue/         会話スクリプトと吹き出し UI
src/audio/            合成サウンド
scripts/make-lod.mjs  LOD 生成
scripts/make-face.mjs 表情用の顔パッチ抽出
scripts/solve-pose.mjs 接触ポーズ（ポケット・眼鏡など）の数値 IK ヘルパー
public/models/        GLB
reference/            元の教室写真と小説テキスト
```
