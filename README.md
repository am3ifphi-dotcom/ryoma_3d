# ✝本質✝教室 ── 理数科B組・両馬二郎と話す

桐葉高校 **北棟・理数科B組**（偏差値60）の教室を 3D で再現し、**両馬二郎**と ✝本質✝ について話せる Web サイト。
同梱の小説『偏差値60の教室から✝本質✝が漏れ出している件について』（一年生編 / 二年生編 / 三年生編 一学期）を読み込んで、
両馬の口調・関係者・世界の細部（コーンスープの不在、窓の真横の室外機、ヘイカツの地形図）を台詞に反映させています。

## 起動

```bash
npm install
npm run dev       # http://localhost:5173
npm run build     # dist/ に出力（static hosting 可）
npm run preview   # ビルド結果を確認
```

`public/ryoma.glb`（約17MB・Tripo 生成の3Dモデル）を読み込みます。
初回ロード時に進捗バーが出ます。モデルは `EXT_meshopt_compression` 圧縮済みなので、
three.js の `MeshoptDecoder` を通して読み込みます。

## できること

- **一人称で歩ける（既定）**：
  - **WASD / 矢印** 歩く、**Shift** 小走り、**C** しゃがむ、**マウス** で視点（クリックでロック、**Esc** で解除）
  - 机・壁・教卓・両馬には当たり判定があります。中央の通路を抜けて黒板の前まで行けます
  - 近づくと照準が変わり、**E** で調べる／話しかける
    - 両馬 → チャット入力へ（そのまま話せる）
    - 黒板・掲示板・スマホ・机・窓 → それについて両馬が話しだす
    - 廊下の自販機 → コーンスープの補充／買い占めが切り替わる
  - **M** キー、または上部の「🎥 カメラ」で従来の orbit カメラ（席/窓/黒板/教室/廊下）に切り替え
  - 右下にミニマップ（自分の向きと両馬の位置）
  - スマホは画面ドラッグで視点、左下のスティックで移動、右下の **E** ボタンで話す
- **ポケットの手を分離して動かす**：
  - モデルには骨が無いので、起動時に**自動で19本の骨を入れて**います（体幹5・腕8・脚6）
  - ウェイトは「骨の線分からの距離」の逆4乗で自動計算。**右手・左手のボーンが独立**しているので、
    ポケットに入った手だけを出して動かせます。継ぎ目は出ません（メッシュは切りません）
  - 左下の**モーション**パレット（または **1〜9** キー）から再生できます  
    ポケット / スマホ / 指さす / 説明 / 考える / 頭をかく / 腕組み / 手を振る / 手を下ろす / ✝本質✝ / お辞儀 / のけぞる
  - 会話中は自動で身振りが入り、セリフの内容（スマホ・黒板・✝本質✝…）に合わせて手が動きます
  - 設定の「腕と手を動かす」をオフにすると、スキャンそのままの静止モデルに戻ります
- **会話**：右のチャットから両馬に話しかける。
  - オフラインの応答エンジン（`src/brain/`）が、原作の台詞・書き込みを元に返します。
  - ユーザーの発言には**本質度**（0〜100）と寸評が付きます。
  - 両馬は時々、会話の内容を**匿名掲示板**（「ヘイカツ雑談スレ」）に書きます。
    三重県臣の名前は必ず一捻りして埋め込まれます。稀に「スレの住人」から返信が付きます。
  - 三重・寺地・零・伊崎・倉石・砂糖がたまに割り込んできます（設定でオフ可）。
  - 34秒黙っていると、向こうから話しかけてきます。
- **3D 教室**（添付の参考写真の配色に合わせてあります：壁 `#ece3c5` / 天井 `#f4ebcc` / 黒板 `#282a2d` / 床 `#8d97a3` / 机 `#d5b8a4`）：
  - カメラ preset：席 / 窓 / 黒板 / 教室 / 廊下（ドラッグで回転・ホイールでズーム）
  - 教卓と提出物、時間割、理数科の心得、掲示板、時計、スピーカー、カーテン、
    ごみ箱・ほうき・消火器、廊下の下駄箱・傘立て、ドアの「理数科Ｂ組」プレート
  - 窓からの光の筋と、光の中を漂う埃。設定で **朝 / 昼 / 夕 / 夜** の時間帯を切り替えられます
  - 窓の外の山と電線、窓の真横で回るエアコンの室外機、廊下の自販機（コーンスープの有無を切替可）
  - 黒板にはヘイカツが書いた等高線・味噌・河岸段丘の断面図
  - 両馬が ✝本質✝ と言うと ✝ の粒子が舞い、頭上に吹き出しが出ます
- **音声**：設定から両馬のセリフを読み上げ（Web Speech API / ja-JP）、室外機の唸りも再現できます。
- **AI接続（任意）**：設定に OpenAI 互換APIのキーを入れると、より自由な会話に切り替わります。
  キーはブラウザの localStorage にのみ保存されます。既定はオフライン・エンジンです。

## メモ

- 3Dモデルは 994,240 頂点 / 1,937,312 三角形あります。重い場合は設定の**軽量モード**を使ってください。
- 起動時に 1〜3 秒ほど「ポケットの手を分離中…」と出ます（19本分のウェイトを約100万頂点ぶん計算しています）。
- モデルの向き：GLB は **+X が正面**です。読み込み時に自動で向きを合わせているので、
  .basic そのまま触る場合は `+Z` を正面として扱ってください（設定の「両馬の向きを反転」で180°回転します）。
- 会話ログは「設定 → 会話を保存(.txt)」で書き出せます。
- 一人称モードでマウスが効かないときは、画面を一度クリックして視点をロックしてください。
